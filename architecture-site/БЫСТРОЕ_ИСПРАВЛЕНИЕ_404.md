# ⚡ Быстрое исправление ошибки 404

## ❌ Проблема:

При переходе на `/blog` или `/contact`:
```
Not Found
The requested URL was not found on this server.
```

## ✅ Решение (2 минуты):

### Шаг 1: Создать файл .htaccess на сервере

1. **Откройте файловый менеджер Timeweb**
2. **Перейдите в** `public_html`
3. **Создайте новый файл** `.htaccess`
4. **Скопируйте и вставьте** этот код:

```apache
<IfModule mod_rewrite.c>
  RewriteEngine On
  RewriteBase /
  RewriteRule ^index\.html$ - [L]
  RewriteCond %{REQUEST_FILENAME} !-f
  RewriteCond %{REQUEST_FILENAME} !-d
  RewriteRule . /index.html [L]
</IfModule>
```

5. **Сохраните файл**

6. **Готово!** Теперь `/blog` должен работать!

---

## 📝 Что делает этот файл:

- Перенаправляет все запросы на `index.html`
- React Router обрабатывает маршруты
- Страницы `/blog`, `/contact` работают

---

## 🔍 Если не работает:

### Вариант 1: Проверить права доступа
- Убедитесь, что файл `.htaccess` доступен для чтения

### Вариант 2: Использовать web.config (для IIS)
- Если Timeweb использует Windows сервер, создайте `web.config` вместо `.htaccess`

### Вариант 3: Настроить через панель
- Панель Timeweb → Сайты → Редиректы
- Добавьте правило перенаправления
