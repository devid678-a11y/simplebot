# Arch Bureau Brutalism WordPress Theme

Бруталистическая тема WordPress для архитектурного бюро. Минималистичный дизайн с акцентом на функциональность и чистоту форм.

## Установка

1. **Загрузите тему в WordPress:**
   - Скопируйте папку `wordpress-theme` в директорию `/wp-content/themes/` вашего WordPress сайта
   - Переименуйте папку в `arch-bureau` (или оставьте как есть)

2. **Активируйте тему:**
   - Перейдите в админ-панель WordPress: `Внешний вид` → `Темы`
   - Найдите тему "Arch Bureau Brutalism" и нажмите "Активировать"

3. **Настройте меню:**
   - Перейдите в `Внешний вид` → `Меню`
   - Создайте новое меню с пунктами: Главная, Блог, Контакты
   - Назначьте его в область "Главное меню"

4. **Создайте страницы:**
   - Создайте страницу "Контакты" (slug: `contact`)
   - Установите главную страницу: `Настройки` → `Чтение` → выберите "Статическая страница" → выберите созданную страницу

## Настройка

### Кастомные поля (опционально)

Для добавления дополнительных секций на главной странице (команда, клиенты, награды и т.д.) можно использовать плагины:
- Advanced Custom Fields (ACF)
- Custom Post Type UI
- Meta Box

### Форма контактов

По умолчанию используется стандартная форма WordPress. Для более продвинутой функциональности рекомендуется установить плагин Contact Form 7.

### Изображения

Тема автоматически создает следующие размеры изображений:
- `arch-bureau-hero`: 1920x1080px (для hero секций)
- `arch-bureau-project`: 800x600px (для проектов)
- `arch-bureau-thumbnail`: 400x300px (для миниатюр)

## Требования

- WordPress 5.0 или выше
- PHP 7.4 или выше
- Поддержка JavaScript в браузере

## Поддержка

При возникновении проблем проверьте:
1. Версию WordPress и PHP
2. Права доступа к файлам темы
3. Консоль браузера на наличие ошибок JavaScript
4. Логи сервера на наличие ошибок PHP
