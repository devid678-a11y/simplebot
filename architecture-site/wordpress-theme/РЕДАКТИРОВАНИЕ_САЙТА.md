# Руководство по редактированию сайта

Этот сайт максимально редактируем через админ-панель WordPress без необходимости редактировать код.

## 📋 Основные настройки

### 1. Настройки темы (Customizer)

Перейдите: **Внешний вид** → **Настроить**

Здесь вы можете изменить:

#### Контактная информация
- **Email** - ваш email адрес
- **Телефон** - номер телефона
- **Адрес** - физический адрес
- **Часы работы** - время работы офиса

#### Социальные сети
- **Instagram URL** - ссылка на Instagram
- **Facebook URL** - ссылка на Facebook
- **LinkedIn URL** - ссылка на LinkedIn

#### Статистика на главной
- **Количество проектов** - число в блоке статистики
- **Лет опыта** - количество лет работы
- **Количество наград** - число наград
- **Количество стран** - число стран работы

#### Hero секция (главная страница)
- **Заголовок** - основной заголовок
- **Подзаголовок** - дополнительный заголовок
- **Описание** - текст под заголовком
- **Фоновое изображение** - изображение для hero секции

## 📝 Управление контентом

### Проекты

**Создание проекта:**
1. Перейдите: **Проекты** → **Добавить новый**
2. Заполните:
   - **Заголовок** - название проекта
   - **Описание** - текст о проекте
   - **Миниатюра** - главное изображение проекта
3. В блоке "Детали проекта" укажите:
   - **Местоположение** - например: "МОСКВА, 2024"
   - **Год** - год реализации
   - **Категория** - ЖИЛАЯ / КОММЕРЧЕСКАЯ / КУЛЬТУРНАЯ / ДРУГАЯ
4. Нажмите **Опубликовать**

Проекты автоматически появятся на главной странице в секции "ПРОЕКТЫ".

### Команда

**Добавление члена команды:**
1. Перейдите: **Команда** → **Добавить нового**
2. Заполните:
   - **Заголовок** - ФИО (например: "АЛЕКСАНДР ИВАНОВ")
   - **Описание** - краткая информация о человеке
   - **Миниатюра** - фотография
3. В блоке "Информация о члене команды":
   - **Должность** - например: "ГЛАВНЫЙ АРХИТЕКТОР"
   - **Опыт работы** - например: "15 ЛЕТ"
4. Нажмите **Опубликовать**

### Услуги

**Добавление услуги:**
1. Перейдите: **Услуги** → **Добавить новую**
2. Заполните:
   - **Заголовок** - название услуги (например: "ЖИЛАЯ АРХИТЕКТУРА")
   - **Описание** - текст об услуге
   - **Миниатюра** - изображение (опционально)
3. В блоке "Детали услуги":
   - **Номер услуги** - например: "01", "02", "03"
   - **Краткое описание** - короткий текст для главной страницы
4. Нажмите **Опубликовать**

Услуги автоматически появятся на главной странице в секции "УСЛУГИ".

### Клиенты

**Добавление клиента:**
1. Перейдите: **Клиенты** → **Добавить нового**
2. Заполните:
   - **Заголовок** - название компании
   - **Миниатюра** - логотип компании
3. В блоке "Информация о клиенте":
   - **Сайт клиента** - URL сайта (опционально)
4. Нажмите **Опубликовать**

### Награды

**Добавление награды:**
1. Перейдите: **Награды** → **Добавить новую**
2. Заполните:
   - **Заголовок** - название награды
   - **Описание** - текст о награде
   - **Миниатюра** - изображение награды (опционально)
3. В блоке "Детали награды":
   - **Год награды** - год получения
   - **Описание** - дополнительное описание
4. Нажмите **Опубликовать**

### Блог (Записи)

**Создание записи блога:**
1. Перейдите: **Записи** → **Добавить новую**
2. Заполните:
   - **Заголовок** - название статьи
   - **Содержание** - текст статьи
   - **Миниатюра** - главное изображение
   - **Категория** - выберите или создайте категорию
3. Нажмите **Опубликовать**

## 🎨 Настройка меню

1. Перейдите: **Внешний вид** → **Меню**
2. Создайте или выберите существующее меню
3. Добавьте пункты:
   - Страницы (Главная, Контакты)
   - Записи (Блог)
   - Произвольные ссылки
4. В разделе "Расположение меню" выберите **"Главное меню"**
5. Нажмите **Сохранить меню**

---

## 📄 Страницы

### Страница "Контакты"

1. Перейдите: **Страницы** → **Добавить новую**
2. Название: **"Контакты"**
3. В настройках страницы установите **Ярлык (slug)**: `contact`
4. Опубликуйте страницу

Форма контактов и информация автоматически подтянутся из настроек темы.

## 🔧 Дополнительные возможности

### Виджеты

Перейдите: **Внешний вид** → **Виджеты**

Доступные области:
- **Боковая панель** - для боковой колонки (если используется)
- **Дополнительный контент (главная)** - для дополнительных блоков на главной странице

### Логотип

1. Перейдите: **Внешний вид** → **Настроить** → **Идентификация сайта**
2. Нажмите **Выбрать логотип**
3. Загрузите изображение логотипа
4. Нажмите **Опубликовать**

---

## 💡 Советы

1. **Изображения**: Используйте качественные изображения. Рекомендуемый размер:
   - Проекты: 800x600px
   - Команда: 400x400px
   - Hero изображение: 1920x1080px

2. **Тексты**: Пишите заголовки заглавными буквами для соответствия стилю (например: "ЖИЛАЯ АРХИТЕКТУРА")

3. **Порядок**: Для услуг можно настроить порядок через "Атрибуты страницы" → "Порядок" (меню_order)

4. **Категории проектов**: Создавайте категории для проектов через **Проекты** → **Категории проектов**

## ❓ Часто задаваемые вопросы

**Q: Как изменить текст в секции "ФИЛОСОФИЯ"?**
A: Эта секция пока статична. Для её редактирования нужно будет добавить настройки в Customizer (можно сделать по запросу).

**Q: Как добавить больше проектов на главную?**
A: По умолчанию показывается 3 проекта. Можно изменить количество в файле `front-page.php` (строка с `posts_per_page`).

**Q: Как изменить порядок услуг?**
A: Используйте плагин "Simple Page Ordering" или измените порядок через "Атрибуты страницы" в редакторе услуги.

**Q: Форма контактов не отправляет письма?**
A: Проверьте настройки почты WordPress или установите плагин Contact Form 7 для более надежной работы.
