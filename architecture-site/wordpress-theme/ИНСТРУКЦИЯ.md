# Инструкция по установке темы Arch Bureau

## Шаг 1: Подготовка файлов

1. Убедитесь, что у вас есть папка `wordpress-theme` со всеми файлами темы
2. Проверьте структуру папок (см. README.md)

## Шаг 2: Загрузка на сервер

### Вариант А: Через FTP/FileZilla

1. Подключитесь к серверу через FTP
2. Перейдите в папку `/wp-content/themes/`
3. Загрузите всю папку `wordpress-theme`
4. Переименуйте папку в `arch-bureau` (опционально)

### Вариант Б: Через файловый менеджер хостинга

1. Войдите в панель управления хостингом
2. Откройте файловый менеджер
3. Перейдите в `/wp-content/themes/`
4. Загрузите папку `wordpress-theme` через загрузку файлов
5. Распакуйте архив, если загружали ZIP

### Вариант В: Через админ-панель WordPress

1. Создайте ZIP-архив папки `wordpress-theme`
2. Переименуйте архив в `arch-bureau.zip`
3. В админ-панели WordPress: `Внешний вид` → `Темы` → `Добавить новую` → `Загрузить тему`
4. Выберите ZIP-файл и загрузите

## Шаг 3: Активация темы

1. В админ-панели WordPress: `Внешний вид` → `Темы`
2. Найдите "Arch Bureau Brutalism"
3. Нажмите "Активировать"

## Шаг 4: Настройка меню

1. Перейдите: `Внешний вид` → `Меню`
2. Создайте новое меню (например, "Главное меню")
3. Добавьте пункты:
   - Главная (ссылка на главную страницу)
   - Блог (ссылка на страницу блога или категорию)
   - Контакты (ссылка на страницу контактов)
4. В разделе "Расположение меню" выберите "Главное меню"
5. Нажмите "Сохранить меню"

## Шаг 5: Создание страниц

### Страница "Контакты"

1. Перейдите: `Страницы` → `Добавить новую`
2. Название: "Контакты"
3. В настройках страницы (справа) установите "Ярлык" (slug): `contact`
4. Опубликуйте страницу

### Главная страница

1. Перейдите: `Настройки` → `Чтение`
2. Выберите "Статическая страница"
3. В поле "Главная страница" выберите созданную страницу (или оставьте "Главная")
4. Сохраните изменения

## Шаг 6: Настройка записей блога

1. Создайте несколько записей: `Записи` → `Добавить новую`
2. Добавьте изображения к записям (миниатюры)
3. Создайте категории для записей (например: "Проекты", "Новости", "Идеи")

## Шаг 7: Проверка работы

1. Откройте главную страницу сайта
2. Проверьте работу меню
3. Проверьте отображение записей блога
4. Проверьте страницу контактов
5. Проверьте адаптивность на мобильных устройствах

## Решение проблем

### Тема не отображается правильно

1. Очистите кеш браузера (Ctrl+F5)
2. Очистите кеш WordPress (если используете плагин кеширования)
3. Проверьте права доступа к файлам (должны быть 755 для папок, 644 для файлов)

### Стили не загружаются

1. Проверьте пути к CSS файлам в `functions.php`
2. Убедитесь, что все файлы CSS загружены в папку `assets/css/`
3. Проверьте консоль браузера на наличие ошибок 404

### JavaScript не работает

1. Проверьте консоль браузера на наличие ошибок
2. Убедитесь, что файл `main.js` загружен в `assets/js/`
3. Проверьте, что скрипт подключен в `functions.php`

### Меню не отображается

1. Убедитесь, что меню создано и назначено в область "Главное меню"
2. Проверьте файл `header.php` на наличие функции `wp_nav_menu()`

## Поддержка

При возникновении проблем проверьте логи ошибок WordPress и сервера.
