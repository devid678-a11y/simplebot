# 🤖 Автоматическая установка WordPress

## ⚠️ Ограничения

Полностью автоматическая установка без вашего участия **невозможна**, потому что нужны:
- Данные для базы данных (нужно создать в панели)
- SSH доступ к серверу (или запуск скрипта)

```dockerfile

```
