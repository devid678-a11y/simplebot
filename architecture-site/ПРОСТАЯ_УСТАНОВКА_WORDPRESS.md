## 🔧 ШАГ 2: Установить WordPress через панель Timeweb

### Способ 1: Автоматическая установка (САМЫЙ ПРОСТОЙ)

1. **Откройте панель Timeweb:**
   - https://timeweb.cloud
   - Войдите в аккаунт

2. **Найдите раздел "Хостинг" или "Сайты":**
   - В меню слева
   - Или через поиск

3. **Нажмите "Создать сайт" или "Установить WordPress":**
   - Если есть кнопка "Установить WordPress" - нажмите её
   - Если нет - создайте новый сайт

4. **Заполните форму:**
   - **Домен:** `wordpress.cb292729.tw1.ru` (или другой поддомен)
   - **Логин админа:** придумайте (например: `admin`)
   - **Пароль:** придумайте надежный пароль
   - **Email:** ваш email

5. **Нажмите "Установить"**

6. **Готово!** WordPress установится автоматически (5-10 минут)

---

### Способ 2: Через Backend приложение (если способ 1 не работает)

1. **Панель Timeweb** → **"Приложения"** → **"Создать приложение"**

2. **Выберите:**
   - Тип: **Backend**
   - Пресет: **Backend app** (ID: 1631 - 250₽/мес)
   - Название: `WordPress CMS`

3. **Создайте приложение**

4. **Создайте базу данных:**
   - Панель → **"Базы данных"** → **"Создать MySQL"**
   - Запомните: имя БД, пользователь, пароль, хост

5. **Подключитесь через SSH:**
   - В панели приложения найдите **"SSH доступ"**
   - Скопируйте команду подключения
   - Запустите в терминале

6. **Запустите скрипт установки:**
   ```bash
   wget https://wordpress.org/latest.tar.gz
   tar -xzf latest.tar.gz
   mv wordpress/* .
   rm -rf wordpress latest.tar.gz
   ```

7. **Настройте wp-config.php:**
   ```bash
   cp wp-config-sample.php wp-config.php
   nano wp-config.php
   ```
   
   Замените:
   ```php
   define('DB_NAME', 'имя_вашей_базы');
   define('DB_USER', 'пользователь_базы');
   define('DB_PASSWORD', 'пароль_базы');
   define('DB_HOST', 'хост_базы');
   ```

8. **Откройте сайт в браузере:**
   - Завершите установку WordPress

## 🔗 ШАГ 3: Настроить связь React с WordPress

### 1. Узнайте адрес WordPress

После установки у вас будет URL, например:
```
https://wordpress.cb292729.tw1.ru
```

### 2. Проверьте API

Откройте в браузере:
```
https://wordpress.cb292729.tw1.ru/wp-json/wp/v2/posts
```

Должен вернуться JSON (может быть пустой массив `[]`).

### 3. Создайте файл `.env` в папке `architecture-site/`

Создайте файл `.env`:
```env
VITE_WORDPRESS_API_URL=https://wordpress.cb292729.tw1.ru/wp-json/wp/v2
```

**Замените** на реальный адрес вашего WordPress!

### 4. Пересоберите React сайт

```bash
cd architecture-site
npm run build
```

### 5. Загрузите обновленные файлы

Загрузите папку `dist` на сервер (как вы делали раньше).

## 🛡️ ШАГ 4: Настроить CORS (чтобы React мог запрашивать данные)

### Через плагин WordPress (САМЫЙ ПРОСТОЙ):

1. **Зайдите в WordPress админку:**
   ```
   https://wordpress.cb292729.tw1.ru/wp-admin
   ```

2. **Плагины** → **Добавить новый**

3. **Найдите:** "CORS Headers" или "WP CORS"

4. **Установите и активируйте**

5. **В настройках плагина укажите:**
   - Разрешенный домен: `https://cb292729.tw1.ru`
