# Проверка белого экрана

## Шаги для диагностики:

1. **Откройте консоль браузера:**
   - Нажмите F12
   - Или правый клик → "Просмотреть код" → вкладка "Console"

2. **Проверьте ошибки:**
   - Если есть красные ошибки, скопируйте их
   - Обычно там указано, в каком файле проблема

3. **Проверьте вкладку Network:**
   - Убедитесь, что все файлы загружаются (статус 200)
   - Если есть 404, значит файл не найден

## Частые причины белого экрана:

1. **Ошибка в JavaScript** - смотрите консоль
2. **Неправильный путь к файлам** - проверьте Network
3. **Проблема с CSS** - проверьте, что стили загружаются
4. **Ошибка в компонентах** - ErrorBoundary покажет ошибку

## Быстрое решение:

Если ничего не помогает, попробуйте:

1. Очистить кеш браузера (Ctrl + Shift + Delete)
2. Перезапустить dev сервер
3. Проверить, что порт 3000 свободен
