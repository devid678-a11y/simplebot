# 🚀 Запуск сайта локально

## Быстрый запуск

### Способ 1: Через npm (рекомендуется)

Откройте терминал в папке проекта и выполните:

```bash
cd "C:\Users\RedmiBook Pro 15\NewApp\cooking-courses-site"
npm run dev
```

Сайт откроется автоматически в браузере по адресу:
**http://localhost:3000**

### Способ 2: Через файл start.bat

Просто дважды кликните на файл `start.bat` в папке проекта.

## 📋 Что вы увидите

После запуска в терминале появится:

```
  VITE v5.x.x  ready in xxx ms

  ➜  Local:   http://localhost:3000/
  ➜  Network: use --host to expose
```

## 🛑 Остановка сервера

Нажмите `Ctrl + C` в терминале, чтобы остановить сервер.

## 🔄 Перезапуск

Если нужно перезапустить:

1. Остановите сервер (`Ctrl + C`)
2. Запустите снова: `npm run dev`

## 📝 Примечания

- Сервер автоматически перезагружает страницу при изменении файлов
- Все изменения видны сразу без перезапуска
- Для остановки используйте `Ctrl + C`

## 🐛 Если не запускается

1. Убедитесь, что установлены зависимости:
   ```bash
   npm install
   ```

2. Проверьте, что порт 3000 свободен

3. Если порт занят, Vite автоматически предложит другой порт
