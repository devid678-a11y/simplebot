# 🚂 Деплой на Railway.app (Пошаговая инструкция)

## ⚡ Быстрый старт (5 минут)

### Шаг 1: Подготовка GitHub репозитория

1. Создайте репозиторий на GitHub (если еще нет)
2. Загрузите все файлы бота:
   ```bash
   git init
   git add .
   git commit -m "Trading bot"
   git remote add origin https://github.com/ваш_username/ваш_репозиторий.git
   git push -u origin main
   ```

### Шаг 2: Регистрация на Railway

1. Перейдите на https://railway.app
2. Нажмите "Start a New Project"
3. Войдите через GitHub
4. Нажмите "Deploy from GitHub repo"
5. Выберите ваш репозиторий

### Шаг 3: Настройка проекта

Railway автоматически определит Python проект, но нужно настроить:

1. **Settings** → **Build Command**: (оставьте пустым, Railway сам установит зависимости)
2. **Settings** → **Start Command**: `python trading_bot_background.py`

### Шаг 4: Переменные окружения

1. Откройте вкладку **Variables**
2. Добавьте переменные:
   - `BYBIT_API_KEY` = ваш API ключ
   - `BYBIT_SECRET_KEY` = ваш секретный ключ

### Шаг 5: Деплой

1. Railway автоматически начнет деплой
2. Откройте вкладку **Deployments** → **View Logs**
3. Дождитесь сообщения: `Бот запущен!` или `Запуск торгового бота`

### Шаг 6: Проверка

1. Откройте **Logs** - должны видеть логи бота
2. Проверьте, что бот получает цены и работает
3. Бот будет работать 24/7!

## 📊 Мониторинг

### Просмотр логов:
- Railway Dashboard → Ваш проект → **Logs**
- Логи обновляются в реальном времени

### Проверка работы:
- В логах должны быть сообщения каждую минуту
- Формат: `[HH:MM:SS] 💰 Баланс: X.XX | Цена: X.XX | Sentiment: X.XX`

## 🔧 Настройка автодеплоя

1. Railway автоматически деплоит при каждом push в GitHub
2. Или отключите автодеплой в Settings → **Source**

## 🛑 Остановка/Перезапуск

- **Остановка**: Settings → **Delete Project**
- **Перезапуск**: Deployments → **Redeploy**
