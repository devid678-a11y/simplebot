# 🚀 Быстрый старт торгового бота

## ✅ Что добавлено:

### 1. Профессиональные улучшения торговли:
- ✅ **Трейлинг-стоп** - автоматически следует за ценой вверх
- ✅ **Частичное закрытие** - закрывает 50% позиции при первом TP, остальное с трейлингом
- ✅ **ATR-based управление рисками** - адаптация размера позиции к волатильности
- ✅ **Защита от просадки** - автоматическая пауза при просадке > 20%
- ✅ **Time-based фильтр** - торговля только в активные часы (5:00-23:00 МСК)
- ✅ **ADX индикатор** - фильтр силы тренда
- ✅ **Детальная статистика** - Sharpe Ratio, Sortino Ratio, Max Drawdown, Recovery Factor

### 2. Фоновый режим:
- ✅ **trading_bot_background.py** - версия без UI, работает постоянно
- ✅ **Автозапуск** - скрипты для Windows
- ✅ **Работа 24/7** - при отключенном спящем режиме

## 📋 Как использовать:

### Вариант 1: Веб-интерфейс (с UI)
```bash
python -m streamlit run trading_web_bot.py --server.headless=true
```
Откройте браузер: http://localhost:8501

### Вариант 2: Фоновый режим (без UI)
```bash
python trading_bot_background.py
```
Или запустите: `start_bot_background.bat`

### Вариант 3: Автозапуск при загрузке Windows
1. Откройте `setup_autostart.md` для подробных инструкций
2. Или используйте Планировщик задач Windows

## ⚙️ Настройка для работы 24/7:

### Важно: Спящий режим
⚠️ Если компьютер в спящем режиме, бот **НЕ РАБОТАЕТ**!

**Решение 1: Отключить спящий режим**
- Запустите `disable_sleep_mode.bat` от имени администратора
- Или: Параметры Windows → Система → Питание → Никогда

**Решение 2: Использовать VPS** (рекомендуется)
- Арендуйте VPS (Timeweb, DigitalOcean, AWS)
- Установите Python и зависимости
- Запустите бота на сервере

## 📊 Новые возможности:

### В веб-интерфейсе:
- **ATR** - волатильность рынка
- **ADX** - сила тренда
- **Просадка** - текущая и максимальная
- **Sharpe Ratio** - риск-скорректированная доходность
- **Sortino Ratio** - учитывает только отрицательную волатильность
- **Recovery Factor** - способность восстанавливаться после просадки

### Торговая логика:
- **Трейлинг-стоп** - защищает прибыль, следуя за ценой
- **Частичное закрытие** - фиксирует 50% прибыли, оставляет остальное для роста
- **Динамический риск** - уменьшает размер позиции при высокой волатильности
- **ADX фильтр** - входит только при наличии тренда (ADX > 20)

## 🔧 Файлы:

- `trading_web_bot.py` - веб-версия с UI
- `trading_bot_background.py` - фоновая версия
- `start_bot_background.bat` - скрипт запуска
- `disable_sleep_mode.bat` - отключение спящего режима
- `setup_autostart.md` - инструкция по автозапуску
