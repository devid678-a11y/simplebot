📸 Инструкция по получению фотографий из Telegram

Вариант 1: Ручное скачивание (рекомендуется)

  1. Откройте канал @OsobnyakKosti в Telegram
  2. Сохраните нужные фотографии на компьютер
  3. Поместите их в папку loft-mansion/images/
  4. Переименуйте главное фото в hero-bg.jpg
  5. Обновите пути в CSS файле

Вариант 2: Автоматическое скачивание

Запустите скрипт для автоматического получения изображений:

node get-telegram-images.js

Примечание: Скрипт может не получить все изображения из-за ограничений Telegram

После получения изображений:

Обновите пути в файле styles.css:

  • Строка ~150: фоновое изображение хедера
  • Строка ~650: изображения в галерее

Пример:

background-image: url('images/hero-bg.jpg');

Важно:

⚠️ Убедитесь, что у вас есть разрешение на использование фотографий из канала!

📧 Свяжитесь с владельцем канала через Telegram для получения разрешения.
