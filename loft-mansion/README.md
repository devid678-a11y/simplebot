# Лофт - Особняк Кости

Сайт для лофта в особняке на Бульваре Рокоссовского.

## 📸 Как добавить фотографии из Telegram канала

### Способ 1: Ручное скачивание (рекомендуется)

1. Откройте канал [@OsobnyakKosti](https://t.me/OsobnyakKosti) в Telegram
2. Найдите лучшие фотографии пространства
3. Сохраните их на компьютер
4. Поместите фотографии в папку `images/`:
   - Главное фото для хедера: `images/hero-bg.jpg`
   - Фото для галереи: `images/gallery-1.jpg`, `images/gallery-2.jpg`, `images/gallery-3.jpg`

### Способ 2: Через браузер

1. Откройте https://t.me/s/OsobnyakKosti в браузере
2. Откройте нужные посты с фотографиями
3. Кликните правой кнопкой на изображение → "Сохранить изображение как..."
4. Сохраните в папку `loft-mansion/images/`

### Способ 3: Автоматический скрипт

```bash
node fetch-telegram-photos.cjs
```

**Примечание:** Скрипт может не работать из-за защиты Telegram. Рекомендуется ручное скачивание.

## 📁 Структура файлов

```

│   ├── hero-bg.jpg     # Фон хедера
│   ├── gallery-1.jpg   # Фото галереи 1
│   ├── gallery-2.jpg   # Фото галереи 2
│   └── gallery-3.jpg   # Фото галереи 3
└── README.md           # Этот файл
```

## 🚀 Размещение на WordPress

1. Загрузите все файлы на сервер WordPress
2. Создайте новую страницу в WordPress
3. Вставьте содержимое `index.html` в редактор (режим HTML)
4. Загрузите `styles.css` и `script.js` через:
   - Плагин для добавления кастомного CSS/JS
   - Или напрямую в тему WordPress
5. Убедитесь, что папка `images/` доступна по пути `/images/`

## ⚠️ Важно

- Убедитесь, что у вас есть разрешение на использование фотографий из канала
- Свяжитесь с владельцем канала через Telegram для получения разрешения
- Все изображения должны быть оптимизированы для веба (рекомендуемый размер: до 500KB)
