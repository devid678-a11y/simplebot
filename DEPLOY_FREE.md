## 🎯 Вариант 1: Railway.app (Самый простой)

### Шаг 1: Подготовка файлов

Создайте файл `Procfile` (для Railway):
```
worker: python trading_bot_background.py
```

Создайте файл `runtime.txt` (опционально):
```
python-3.11
```

### Шаг 2: Регистрация на Railway

1. Перейдите на https://railway.app
2. Войдите через GitHub
3. Нажмите "New Project" → "Deploy from GitHub repo"
4. Выберите ваш репозиторий

### Шаг 3: Настройка переменных окружения

В Railway Dashboard:
1. Откройте ваш проект
2. Перейдите в "Variables"
3. Добавьте:
   - `BYBIT_API_KEY` = ваш ключ
   - `BYBIT_SECRET_KEY` = ваш секрет

### Шаг 4: Настройка деплоя

1. Railway автоматически определит Python проект
2. Укажите команду запуска: `python trading_bot_background.py`
3. Нажмите "Deploy"

### Шаг 5: Проверка

- Откройте "Logs" в Railway Dashboard
- Проверьте, что бот запустился
- Проверьте файл `trading_bot_data.json` (будет в файловой системе Railway)

## 🎯 Вариант 2: Render.com

### Шаг 1: Подготовка

Создайте файл `render.yaml`:
```yaml
services:
  - type: worker
    name: trading-bot
    env: python
    buildCommand: pip install -r requirements.txt
    startCommand: python trading_bot_background.py
    envVars:
      - key: BYBIT_API_KEY
        sync: false
      - key: BYBIT_SECRET_KEY
        sync: false
```

### Шаг 2: Регистрация

1. Перейдите на https://render.com
2. Войдите через GitHub
3. Нажмите "New" → "Background Worker"
4. Подключите репозиторий

### Шаг 3: Настройка

1. **Build Command**: `pip install -r requirements.txt`
2. **Start Command**: `python trading_bot_background.py`
3. Добавьте Environment Variables:
   - `BYBIT_API_KEY`
   - `BYBIT_SECRET_KEY`

### Шаг 4: Keep-Alive (чтобы не засыпал)

Создайте файл `keep_alive.py`:
```python
import requests
import time
import os

# URL вашего бота (если есть веб-интерфейс)
# Или просто периодический пинг
while True:
    try:
        # Можно пингать сам себя или внешний сервис
        time.sleep(300)  # Каждые 5 минут
    except:
        pass
```

Или добавьте в `trading_bot_background.py` простой HTTP сервер для keep-alive.

## 🔧 Адаптация кода для облака

Нужно немного изменить `trading_bot_background.py` для работы в облаке:

### Изменения:

1. **Путь к файлу данных** - использовать абсолютный путь или переменную окружения
2. **Логирование** - добавить более детальное логирование
3. **Обработка ошибок** - улучшить обработку сетевых ошибок

Создам адаптированную версию:

```python
# В начале файла trading_bot_background.py добавить:
import os

# Определяем путь к файлу данных
if os.getenv('RAILWAY_ENVIRONMENT') or os.getenv('RENDER'):
    # В облаке используем рабочую директорию
    DATA_FILE = os.path.join(os.getcwd(), 'trading_bot_data.json')
else:
    # Локально
    DATA_FILE = 'trading_bot_data.json'
```
