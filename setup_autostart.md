# Настройка автозапуска торгового бота

## Важно: Работа в спящем режиме

⚠️ **ВНИМАНИЕ**: Если компьютер переходит в спящий режим, бот **НЕ МОЖЕТ** работать, так как все процессы останавливаются.

### Решения:

1. **Отключить спящий режим** (рекомендуется для постоянной работы):
   - Откройте "Параметры Windows" → "Система" → "Питание и спящий режим"
   - Установите "Никогда" для "Переводить компьютер в спящий режим"
   - Или используйте команду: `powercfg /change standby-timeout-ac 0`

2. **Использовать VPS/Облачный сервер** (лучший вариант):
   - Арендуйте VPS (например, на Timeweb, DigitalOcean, AWS)
   - Установите Python и зависимости
   - Запустите бота на сервере
   - Бот будет работать 24/7

3. **Использовать Wake-on-LAN** (продвинутый вариант):
   - Настройте компьютер на пробуждение по сети
   - Используйте внешний сервис для пробуждения

## Способ 1: Автозапуск через Планировщик задач Windows

### Шаги:

1. Откройте "Планировщик задач" (Task Scheduler)
   - Нажмите Win+R, введите `taskschd.msc`, нажмите Enter

2. Создайте новую задачу:
   - Нажмите "Создать задачу" (Create Task)

3. Вкладка "Общие":
   - Имя: `Trading Bot Auto Start`
   - Описание: `Автозапуск торгового бота при входе в систему`
   - Отметьте: "Выполнять с наивысшими правами" (Run with highest privileges)
   - Выберите: "Настроить для: Windows 10"

4. Вкладка "Триггеры":
   - Нажмите "Создать" (New)
   - Начало задачи: "При входе в систему"
   - Отметьте: "Включено"
   - Нажмите "ОК"

5. Вкладка "Действия":
   - Нажмите "Создать" (New)
   - Действие: "Запуск программы"
   - Программа или сценарий: `C:\Users\RedmiBook Pro 15\NewApp\start_bot_background.bat`
   - Или укажите полный путь к Python:
     ```
     C:\Users\RedmiBook Pro 15\AppData\Local\Programs\Python\Python311\python.exe
     ```
   - Аргументы: `trading_bot_background.py`
   - Рабочая папка: `C:\Users\RedmiBook Pro 15\NewApp`

6. Вкладка "Условия":
   - Снимите галочку "Запускать только при питании от электросети"
   - Отметьте "Пробуждать компьютер для выполнения задачи" (если нужно)

7. Вкладка "Параметры":
   - Отметьте "Выполнять задачу немедленно, если пропущен запланированный запуск"
   - Отметьте "При сбое запускать задачу повторно каждые: 1 минута"
   - Количество попыток: 3

8. Нажмите "ОК" и введите пароль администратора

## Способ 2: Автозапуск через папку автозагрузки

### Шаги:

1. Нажмите Win+R, введите `shell:startup`, нажмите Enter
   - Откроется папка автозагрузки

2. Создайте ярлык для `start_bot_background.bat`:
   - Правой кнопкой → Создать → Ярлык
   - Укажите путь: `C:\Users\RedmiBook Pro 15\NewApp\start_bot_background.bat`
   - Назовите: "Trading Bot"

3. (Опционально) Настройте ярлык:
   - Правой кнопкой на ярлык → Свойства
   - Вкладка "Ярлык" → "Окно: Свернутое в значок" (чтобы не показывать окно)

## Способ 3: Запуск как служба Windows (продвинутый)

Для запуска бота как службы Windows используйте NSSM (Non-Sucking Service Manager):

1. Скачайте NSSM: https://nssm.cc/download
2. Распакуйте и запустите `nssm.exe install TradingBot`
3. Укажите:
   - Path: путь к Python
   - Startup directory: `C:\Users\RedmiBook Pro 15\NewApp`
   - Arguments: `trading_bot_background.py`
4. Запустите службу: `nssm start TradingBot`

## Проверка работы

После настройки автозапуска:

1. Перезагрузите компьютер
2. Проверьте, что бот запустился:
   - Откройте Диспетчер задач (Ctrl+Shift+Esc)
   - Найдите процесс `python.exe` с аргументом `trading_bot_background.py`
3. Проверьте логи:
   - Откройте файл `trading_bot_data.json`
   - Проверьте поле `last_update` - должно обновляться каждую секунду

## Остановка бота

Если нужно остановить бот:

1. Откройте Диспетчер задач
2. Найдите процесс `python.exe` с `trading_bot_background.py`
3. Завершите процесс

Или создайте файл `stop_bot.bat`:
```batch
@echo off
taskkill /F /FI "WINDOWTITLE eq *trading_bot_background*" /T
```

## Мониторинг

Для мониторинга работы бота:

1. Проверяйте файл `trading_bot_data.json` - он обновляется каждые 30 секунд
2. Используйте веб-интерфейс: запустите `trading_web_bot.py` для просмотра статистики
3. Создайте скрипт для отправки уведомлений (Telegram, Email)

## Рекомендации

1. **Используйте VPS** для 24/7 работы
2. **Настройте мониторинг** - получайте уведомления о критических событиях
3. **Регулярно проверяйте логи** - следите за производительностью
4. **Делайте резервные копии** файла `trading_bot_data.json`
5. **Тестируйте на Paper Trading** перед реальной торговлей

## Отключение спящего режима (команда)

Откройте PowerShell от имени администратора и выполните:

```powershell
# Отключить спящий режим при питании от сети
powercfg /change standby-timeout-ac 0

# Отключить спящий режим при питании от батареи
powercfg /change standby-timeout-dc 0

# Отключить отключение дисплея
powercfg /change monitor-timeout-ac 0
powercfg /change monitor-timeout-dc 0
```

## Включение спящего режима обратно

```powershell
# Включить спящий режим через 30 минут
powercfg /change standby-timeout-ac 30
```
