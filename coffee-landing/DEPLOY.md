# 🚀 Быстрый деплой лендинга

## ⚡ Вариант 1: Netlify Drop (САМЫЙ БЫСТРЫЙ - 30 секунд!)

### Шаги:
1. Откройте: https://app.netlify.com/drop
2. Перетащите папку `coffee-landing` в браузер
3. Готово! Получите URL вида: `https://random-name-123.netlify.app`

**Всё! Никаких настроек, никакой авторизации!**

---

## 🌟 Вариант 2: Vercel (Через CLI)

### Установка и деплой:
```bash
cd coffee-landing
npx vercel --prod
```

Следуйте инструкциям в терминале.

## 📦 Вариант 3: GitHub Pages

Если проект в Git:
1. Создайте репозиторий на GitHub
2. Загрузите файлы
3. Settings → Pages → Source: main branch
4. Готово!
