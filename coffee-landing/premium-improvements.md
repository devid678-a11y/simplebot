# 🎨 Рекомендации по улучшению дизайна для премиального ощущения

## 1. Типографика (КРИТИЧНО)

### Добавить премиальные шрифты:
```html
<!-- В <head> добавить -->
<link rel="preconnect" href="https://fonts.googleapis.com">
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
<link href="https://fonts.googleapis.com/css2?family=Playfair+Display:wght@400;500;600;700&family=Inter:wght@300;400;500;600&display=swap" rel="stylesheet">
```

### CSS изменения:
- Заголовки: `font-family: 'Playfair Display', serif;` (элегантный serif)
- Основной текст: `font-family: 'Inter', sans-serif;` (современный sans-serif)
- Увеличить `letter-spacing` для заголовков: `letter-spacing: 0.05em;`
- Увеличить размеры заголовков на 20-30%

## 2. Цветовая палитра

### Добавить золотые акценты:
```css
:root {
    --gold-primary: #D4AF37;
    --gold-light: #F4E4BC;
    --gold-dark: #B8941F;
    --dark-bg: #0A0A0A; /* Более глубокий черный */
    --dark-surface: #1A1A1A;
}
```

### Применить к:
- Акцентным элементам (кнопки, цены)
- Подчеркиваниям заголовков
- Иконкам и декоративным элементам

## 3. Пространство и отступы

### Увеличить:
- Отступы между секциями: `padding: 120px 0;` (вместо текущих)
- Отступы внутри карточек: `padding: 40px;`
- Межстрочный интервал: `line-height: 1.8;` для текста

## 4. Визуальные эффекты

### Тени для карточек:
```css
box-shadow: 0 20px 60px rgba(0, 0, 0, 0.3),
            0 0 0 1px rgba(255, 255, 255, 0.05);
```

### Плавные анимации:
- Fade-in при скролле
- Параллакс для hero-изображения
- Плавное появление карточек
