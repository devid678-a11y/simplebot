# Mindful Gate - Android App

Приложение для осознанного потребления информационного контента с экраном паузы.

## Возможности

- **Экран паузы** - появляется при открытии выбранных приложений
- **Редактор контента** - свободное размещение текста, изображений и рисование
- **Настройки** - выбор приложений для мониторинга, время удержания, статистика
- **Перехват запуска** - автоматическое показ экрана паузы при открытии приложений

## Открытие в Android Studio

1. Откройте Android Studio
2. Выберите `File` → `Open`
3. Перейдите в папку `mindful-gate-app` и выберите её
4. Дождитесь синхронизации Gradle
5. Подключите Android устройство или запустите эмулятор
6. Нажмите `Run` (Shift+F10) для запуска приложения

## Настройка разрешений

Для работы перехвата приложений необходимо:

1. **Разрешение на отображение поверх других окон:**
   - Перейдите в Настройки → Приложения → Mindful Gate → Дополнительные разрешения
   - Включите "Отображение поверх других окон"

2. **Accessibility Service:**
   - Перейдите в Настройки → Специальные возможности
   - Найдите "Mindful Gate" и включите службу

3. **QUERY_ALL_PACKAGES (Android 11+):**
   - Разрешение запрашивается автоматически при первом запуске

## Использование

1. **Редактор:** Создайте свой экран паузы с текстом, изображениями и рисунками
2. **Настройки:** Выберите приложения для мониторинга и установите время удержания
3. **Экран паузы:** При открытии выбранного приложения появится экран паузы
4. **Продолжить:** Зажмите кнопку "Продолжить" на указанное время
5. **Закрыть:** Нажмите "Закрыть" для возврата

## Технологии

- Kotlin
- Jetpack Compose
- Material Design 3
- SharedPreferences для хранения данных
- AccessibilityService для перехвата приложений
- WindowManager для показа оверлея

## Минимальные требования

- Android 8.0 (API 26) или выше
- Android Studio Hedgehog или новее
